# NexaVault — Frontend

This is the frontend application for **NexaVault**, built with React, Vite, and Tailwind CSS using a Deep Teal engineering-grade visual theme.

## Structure

```
frontend/
├── public/
├── src/
│   ├── assets/
│   │   ├── images/
│   │   ├── icons/
│   │   └── fonts/
│   ├── components/
│   │   ├── ui/
│   │   └── layout/
│   ├── pages/
│   │   └── Login/
│   │       ├── Login.jsx
│   │       └── Login.css
│   ├── styles/
│   │   ├── globals.css
│   │   └── variables.css
│   ├── App.jsx
│   └── main.jsx
├── .gitignore
├── index.html
├── package.json
├── package-lock.json
├── postcss.config.js
├── tailwind.config.js
└── vite.config.js
```

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

To build for production:

```bash
npm run build
```
